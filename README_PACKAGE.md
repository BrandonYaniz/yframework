# yFramework Planning and Codex Package

This package contains the five authoritative consolidated architecture/planning source files under `docs/architecture/` plus a complete `.codex` control directory and task-file set for tasks 001 through 881.

The `.codex` task files intentionally reference compact milestone contracts and authoritative architecture sources rather than duplicating every architectural paragraph into every task, reducing drift while still giving Codex a concrete per-task execution contract.
