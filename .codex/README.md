# yFramework Codex Workspace

This directory is the implementation-control surface for Codex. The authoritative architecture remains in `docs/architecture/`. Tasks are executable only when their task file exists here and all prerequisites are complete.

Start with `INSTRUCTIONS.md`, then `DECISION_AUTHORITY.md`, `ARCHITECTURE_INDEX.md`, `CURRENT_MILESTONE.md`, and the target task file.

`TASKS/` contains tasks 001 through 881. `MILESTONES/` contains compact milestone contracts. `STATE/` records execution state without rewriting architecture.
