# Milestone 6: Widgets and Runtime Settings

## Governing contract

Widgets are display-only compiled definitions with MariaDB instances, areas, and placements. Placement may filter routes, descendants, handlers, actions, and action kinds; exclusions win. Widget configuration is typed and validated before snapshot activation. Stored content uses a narrow directive parser, never arbitrary Go-template execution. Widget recursion, nesting, and count are bounded. Runtime settings are code-registered typed definitions. Dynamic setting precedence is compiled default, permitted TOML override, then MariaDB override. Deployment-only settings cannot be overridden from MariaDB. Runtime setting updates are revisioned, audited, validated, and activated through immutable snapshots. Invalid candidate state never replaces the active snapshot.
