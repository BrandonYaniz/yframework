# Milestone 9: External Integration Runtime

## Governing contract

Components never perform raw external transport. They depend on typed domain ports, applications bind adapters, and adapters use framework integration primitives. The framework must not expose a generic external.Call service locator. Shared runtime mechanics include credential handling/redaction, TLS, timeouts, cancellation, bounded retries, aggregate retry budgets, rate limiting, circuit breakers, health, tracing, and normalized errors. Public web fetches require SSRF-safe destination validation, redirect revalidation, and size/time bounds. Retry ownership must be explicit so transport, SDK, and job retry loops do not multiply. Required integrations may affect readiness; optional failures degrade capability without necessarily making the process unready.
