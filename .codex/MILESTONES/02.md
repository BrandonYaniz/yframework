# Milestone 2: MariaDB and Migrations

## Governing contract

MariaDB-only database support, transaction helpers, compatibility checks, advisory migration lock, deterministic checksummed migrations, separate foreground/background pools, and nonmutating validation. Database-sensitive behavior is tested against real MariaDB.
