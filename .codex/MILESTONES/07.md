# Milestone 7: Jobs

## Governing contract

There is one ordinary durable executable background FIFO lane in v1, with no queue_name and no execution priority. Jobs have compact current rows plus separate payload/result and attempt history. Claims use short MariaDB transactions with FOR UPDATE SKIP LOCKED, commit before handler execution, and distinguish claimed from running. Attempt count increments only when running begins. Ownership uses a cryptographically random secret lease token and MariaDB time. Heartbeat, progress, completion, failure, retry, cancellation, workflow advancement, and concurrency release are fenced by current ownership. Execution is at-least-once, handlers must be idempotent and cancellation-aware, retries are bounded, and non-cooperative goroutines are never falsely killed. Expired claimed work does not consume an attempt; expired running work does. Idle-only is an eligibility rule in the same lane. Shutdown stops claims, continues heartbeats, drains, cancels at deadline, and never releases a lease while its handler may still run.
