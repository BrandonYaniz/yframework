# Milestone 14: Public API and Compatibility Freeze

## Governing contract

No new architecture is introduced. Inventory and minimize every exported symbol and public package. Public APIs must not expose persistence rows, internal numeric IDs, secrets, ownership tokens, registry internals, or generic service-location patterns. context.Context carries cancellation/deadlines/metadata, not dependencies. Stable dynamic names and persisted identifiers are compatibility-sensitive. Public APIs remain typed and narrow: actions presentation-neutral, resource authorization component-owned, jobs/workflows/schedules hide execution internals, external integrations remain adapter infrastructure, messaging hides SMTP, LLM hides yllmd, and localization does not become a universal content store. Freeze error inspection semantics, semantic-versioning/deprecation policy, configuration compatibility, persisted-name compatibility, and public testing helpers. internal/testapp and representative fixtures must consume only public APIs. Implementation must be reconciled against architecture sources before freeze.

A task is complete only when its behavior matches the governing sources, relevant tests pass, exported API changes are documented, secrets are redacted, ownership boundaries remain intact, and no architecture-affecting decision was silently invented.
